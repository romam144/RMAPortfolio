RAMICHAI LIVE SITE

Upload everything inside this folder to your public web host.

This folder is public-only:
- no admin page
- no server.js
- no password
- no upload endpoint
- no API routes

Main pages:
- index.html
- work.html
- personal.html
- films.html
- project.html

The website reads its content from:
- data/content.json

To preview it locally, use START-RAMICHAI-LIVE-PREVIEW.bat from the outputs folder.

When you update content through the private admin folder, export the saved content back into this live folder before uploading again.
